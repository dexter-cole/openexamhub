# OpenExamHub

[OpenExamHub](https://openexamhub.com) is a network of free, source-linked licensing exam prep sites: practice questions, study guides, and current licensing facts, each tied to a primary official source and a review date. No signup, no credit card.

## What you'll find

- Free practice questions and diagnostics with source-linked answer review
- Study guides and exam overviews for licensing exams
- Current licensing facts and fees with review dates
